# Content Opportunity Report

由于当前暂无 Google Search Console 和 Bing Webmaster Tools 的 API 接入与实际数据读取，本报告依据预期架构建立基线，等待真实数据回流后再做填充和动作执行。

## 立即优化
（已经有曝光、排名较好）
*暂无真实数据，待 API / 人工提取 GSC 曝光大于 0 且排名在 1~20 位的页面后填入此处。*
**优化动作：**
- 修改 Title / Description 提高 CTR。
- 检查首屏加载和用户停留意愿。

## 需要补强
（有曝光但排名较低，位于 21~50 名）
*暂无真实数据，待分析后填入。*
**优化动作：**
- 增加当前网页的内容深度和字数。
- 从 Hub 或高权重文章向其添加内链传递权重。

## 值得新建
（存在搜索需求，但目前没有对应页面）
*基于经验预判：*
- **Clash Verge 常见报错排查大全** (如 timeout, port is used)
- **Mac / Windows 各平台使用 Clash Verge 最佳实践差异**

## 暂不处理
（数据不足，完全没有 Impression / 尚未收录，名次在 50 开外）
*目前绝大多数处于此状态。*
**动作：**
- 优先处理 Sitemap 和 Canonical 的结构性 Bug。
- 等待爬虫完整抓取。
