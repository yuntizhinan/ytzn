扬帆云怎么配置？全平台客户端新手使用教程

全面覆盖 Windows, macOS, Android 和 iOS，新手可在三分钟内快速上手。

Windows 系统 Clash Verge 配置流程

  1. 在下方下载中心下载 Windows Clash Verge 客户端。
  2. 登录扬帆云官方后台，找到一键订阅功能，复制 Clash 订阅地址。
  3. 打开 Clash Verge，点击左侧菜单的“订阅”选项。
  4. 在顶部的输入框中粘贴刚刚复制的扬帆云订阅地址，点击“导入”。
  5. 导入成功后，鼠标单击选中刚才新增的文件名，使其高亮生效。
  6. 返回“代理”选项，选择适合的地区节点（推荐香港/新加坡）。
  7. 在“系统代理”开关处点击启用，即可开始科学上网。

macOS 系统 Clash Verge 配置流程

  1. 在下载中心获取 macOS Clash Verge 版本的 dmg 安装包，安装并允许运行权限。
  2. 在扬帆云机场官网后台复制 Clash 一键配置链接。
  3. 启动软件，选择左侧的 Profiles 页面，粘贴链接并点击 Import 导入。
  4. 等待软件下载完成配置，左键点击该配置文件进行激活。
  5. 选择 Proxies，在 Rule 规则模式下选择你的低延迟目标加速节点。
  6. 打开 System Proxy 系统代理全局开关，开启高速跨境连接。

Android 安卓系统 Clash Meta 配置流程

  1. 下载并安装 Clash Meta (Clash for Android) 的 apk 格式程序包。
  2. 登录扬帆云后台，复制配置订阅，或者选择“一键导入到 Clash”。
  3. 如果选择复制链接，在软件中点击“配置” - “新配置” - “从URL导入”。
  4. 在 URL 输入栏中贴入扬帆云订阅链接，设置名称后点击保存。
  5. 在配置列表中选中该文件，返回主菜单点击“启动”按钮。
  6. 进入“控制面板” - “代理”，选择目标地区加速节点即可畅行网络。

iOS 苹果系统 Shadowrocket 小火箭配置流程

  1. 使用非国区 (如美区、港区) 的 Apple ID 登录 App Store，搜索并下载 Shadowrocket。
  2. 登录扬帆云官网控制台，在订阅中心找到并复制“Shadowrocket 订阅链接”。
  3. 打开 Shadowrocket，软件会自动检测到剪切板的链接并提示添加，点击“确定”。
  4. 若无提示，点击右上角 “+” 号，类型选择 “Subscribe (订阅)”，URL 贴入订阅链接，点击“完成”。
  5. 在自动加载的节点列表中选择任意节点，点击前面的圆圈选中。
  6. 开启软件最上方的“未连接”开关，在弹出的 VPN 配置请求中点击“允许”，指纹或密码确认即可。
