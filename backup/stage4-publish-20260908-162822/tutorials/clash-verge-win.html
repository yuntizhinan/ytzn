Windows 平台 Clash Verge 配置指南 (含图文)

作者: 发布于: 2026-08-09

对于 Windows 10 和 Windows 11 用户而言，在 2026 年，Clash Verge Rev 已经完全取代了曾经的 Clash for Windows (CFW)，成为最受推崇的现代界面代理客户端。它不仅完美支持最新的 Meta 内核，还支持中文字体路径、自定义合并配置文件（Merge）、TUN 虚拟网卡模式等高阶功能。本篇《Windows 平台 Clash Verge 配置指南》将通过图文并茂的方式，手把手教您如何完成从下载、安装、导入订阅到开启系统代理的全过程。

如果您还没有稳定可靠的订阅节点，请务必先查阅我们的 《2026年稳定高速机场推荐指南》 和最新的 机场排行榜。

一、下载与安装 Clash Verge Rev

第一步是获取官方纯净版安装包。市面上有很多冒充官方的伪装网站，内置木马病毒，请务必认准官方开源仓库发布地址。

  • 官方 GitHub 下载页： 在浏览器搜索 Clash Verge Rev GitHub Releases，找到最新版（Latest）。
  • 选择正确的安装包： 对于绝大多数 Windows 10/11 用户（Intel 或 AMD 处理器），请下载 Clash.Verge_x.x.x_x64-setup.exe。如果你使用的是基于 ARM 处理器的 Windows（如部分 Surface Pro），请下载 arm64-setup.exe。
  • 安装： 双击下载好的 exe 文件，一路点击“下一步 (Next)”即可。安装路径支持中文，但为了最大兼容性，建议保持默认的 C 盘路径。

二、获取并导入机场订阅链接

安装完成后，打开 Clash Verge。它的界面左侧是导航栏，右侧是操作区。我们首先需要将机场的节点信息（配置文件）导入进来。

  1. 复制订阅： 登录您的机场后台，找到“一键导入 Clash”或“复制 Clash 订阅链接”的按钮。如果您的机场比较老旧，请寻找“复制通用订阅链接”。
  2. 进入 Profiles 面板： 在 Clash Verge 左侧导航栏中，点击 “配置 (Profiles)”。
  3. 粘贴并导入： 在右上方的输入框中，粘贴 (Ctrl+V) 您刚刚复制的订阅链接，然后点击右侧的蓝色 “导入 (Import)” 按钮。
  4. 激活配置 (非常关键)： 稍等几秒，系统会下载并解析出一个带有机场名字的文件卡片。请务必用鼠标左键点击一下这张卡片，使其背景变色或出现一个打勾图标 ✓，这才表示软件正在使用该配置！

⚠️ 新手常见错误：导入后忘记点击激活卡片，导致后续开启代理也上不了网。

三、开启系统代理与选择分流模式

配置导入且激活后，我们需要打开开关并选择如何使用这些节点。

1. 打开系统代理 (System Proxy)

点击左侧导航栏的 “设置 (Settings)”，找到 “系统代理 (System Proxy)” 选项，将其右侧的开关打开（变亮）。此时，Windows 系统的网络流量就已经开始被接管了。

2. 确认路由模式为“规则 (Rule)”

点击左侧导航栏的 “代理 (Proxies)”。在页面最上方，你会看到三个模式选项：全局 (Global)、规则 (Rule)、直连 (Direct)。请永远选中“规则 (Rule)”模式。这样，软件会自动让国内流量（如微信、淘宝）直连，国外流量（如 Google、YouTube）走代理，省时省力省流量。

3. 选择你心仪的节点

在 “代理 (Proxies)” 页面下方，展开名为 Proxy 或 节点选择 的策略组分组。你会看到一长串国家地区的节点列表。点击你喜欢的节点（如“香港 IPLC 01”），节点前方出现指示符即代表选中。如果您不知道怎么选节点，请参考本站另一篇干货：《教你三步挑出好节点》。

四、高阶必修：开启 TUN 虚拟网卡模式 (解决部分软件不走代理)

如果你发现浏览器可以翻墙，但是某些电脑软件（如 Steam 商店加载、Telegram 客户端、部分跨国游戏、甚至是某些旧版命令行工具）依然连不上外网，那是因为它们不遵循 Windows 的系统 HTTP 代理规范。

解决方案：开启 TUN 模式。 TUN 模式会在系统底层创建一个虚拟网卡，强制接管整台电脑 100% 的网络流量。

  1. 返回 Clash Verge 的 “设置 (Settings)” 页面。
  2. 找到 “TUN 模式 (TUN Mode)”。
  3. 点击开关。此时系统可能会弹出 UAC 提升权限的提示窗口（“是否允许此应用对你的设备进行更改”），请务必点击 “是”。
  4. 开关变亮后，TUN 模式即刻生效！你可以进入 “连接 (Connections)” 面板，看到所有底层应用的流量（包括 UDP 协议）都已经成功被路由。

五、配置合并 (Merge) 与自定义规则进阶

Clash Verge Rev 最强大的特性之一就是支持可视化的“配置合并 (Merge)”。有些机场主提供的规则比较简陋，你希望加入自己去广告的规则，或者强制某个网址走特定的节点，过去你需要手写复杂的 YAML，现在只需简单设置：

  • 点击左侧 “订阅 (Subscriptions)”，点击 新建 (New) -> Merge (合并)。
  • 在里面可以插入你自定义的路由规则（Routing Rules）或 DNS 覆写（DNS Override）。
  • 右键点击你原本的机场配置，选择“使用此 Merge”。以后无论机场怎么更新订阅，你的自定义规则都不会被覆盖。

六、结语

现代版的 Clash Verge Rev 不仅修复了大量历史遗留问题，大幅降低了内存占用，更将复杂的内核逻辑封装在了优雅的图形界面之下。只要认真按照上述图文步骤执行，你就能在 Windows 系统上获得极致顺滑的科学上网体验。
