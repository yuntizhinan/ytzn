五、流媒体与 AI 工具解锁实测

流媒体和 AI 工具解锁是评判一款机场实用价值的核心指标。根据编辑部参考测试，宝云机场在常见平台上的表现如下：

1. ChatGPT / Gemini / Claude 等 AI 工具

宝云的日本和美国节点对 ChatGPT（OpenAI）、Google Gemini 等 AI 服务保持较好的解锁能力。连接美国节点时 OpenAI 风控触发率较低，日本节点在 Gemini 和 Claude 上表现稳定。建议 AI 工具调用时优先选择日本或美国节点，并保持全局代理模式以避免 IP 混用触发风控。

2. YouTube 4K 高清串流

YouTube 4K 对带宽的需求约为 20–25 Mbps，宝云的日本和香港节点在非晚高峰时段均可稳定承载 4K 播放，缓冲时间一般在 2–5 秒内。晚高峰（20:00–23:00）节点负载增加时建议切换至台湾或新加坡节点作为备选。

3. Netflix / Disney+ / 常规流媒体

宝云对 Netflix、Disney+ 等常规流媒体提供基础解锁支持。台湾、日本、新加坡节点解锁对应地区内容的概率较高，香港节点因原生 IP 合规性差异，部分平台可能出现地区不符提示。建议先通过月付套餐测试本地节点对目标平台的实际解锁效果。

宝云机场使用 VLESS 协议，兼容目前绝大多数主流代理客户端，配置流程简单，通过订阅链接一键导入即可完成。以下是各平台的推荐方案：

1. Windows / macOS（推荐：Clash Verge Rev）

  1. 下载并安装最新版 Clash Verge Rev（开源免费，支持 Windows / macOS）。
  2. 登录宝云机场后台，进入"我的订阅"，复制 Clash 订阅链接。
  3. 打开 Clash Verge，点击左侧"订阅（Profiles）"，粘贴链接并点击导入，等待节点同步完成。
  4. 切换到"代理（Proxies）"页面，选择规则模式实现国内外智能分流。
  5. 日常浏览选择香港/台湾节点；YouTube 4K 或 AI 调用选择日本/美国节点。

如遇导入失败，可参考站内 Windows 客户端配置教程 进行排查。

2. iOS（推荐：Shadowrocket 小火箭）

  1. 使用非大陆区 Apple ID 登录 App Store，下载 Shadowrocket（付费 $2.99，一次性买断）。如需注册美区 Apple ID，可参考 美区 Apple ID 注册教程。
  2. 在宝云后台复制 Shadowrocket 专用订阅链接。
  3. 打开小火箭，点击右上角 "+"，类型选 Subscribe（订阅），粘贴链接并保存。
  4. 返回主界面后向下拉动刷新节点列表，选择目标节点并点击连接按钮。

3. Android（推荐：v2rayNG）

  1. 从 GitHub 或 Google Play 下载最新版 v2rayNG。
  2. 在宝云后台复制通用订阅链接（v2ray 格式）。
  3. 打开 v2rayNG，点击左上角菜单 → 订阅设置 → 右上角 "+" → 粘贴链接并保存。
  4. 返回主界面，点击右上角三点菜单 → 更新订阅，加载所有 VLESS 节点后选择目标节点连接。

如需了解 Android 客户端的详细配置，可参考站内 Android 安卓客户端教程。
