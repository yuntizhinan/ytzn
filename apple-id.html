共享 Apple ID 常见疑问

Q: 用共享 ID 会不会把手机锁了?

只要按本页做——只在「App Store」登录下载，用完退出，就没有锁机风险。锁机(激活锁)只发生在你把共享账号登录到「设置 → 顶部 Apple ID」整机的情况，那样对方能通过「查找」远程锁定，千万别这么做。

Q: 为什么提示"需要验证码 / 双重认证"?

说明该账号临时开启了双重验证或正被占用，你收不到验证码。别纠结，直接换账号池里的下一个账号即可。

Q: 我的照片、通讯录会泄露吗?

不会。只在 App Store 登录不会同步任何 iCloud 数据(照片/通讯录/备忘录)。前提仍是:不要在「设置」里整机登录。

Q: 下载的 App 之后还能更新吗?

App 装好后打开使用不需要账号。更新时会要求当时下载用的 ID 密码——建议之后用自己的美区 Apple ID 覆盖，或临时登共享 ID 更新。App 本身不会因为退出账号而失效。
