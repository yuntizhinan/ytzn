安全警示：某开源机场面板爆发零日漏洞（0-Day），超百家机场数据库遭勒索脱库，用户订阅 Token 与真实 IP 泄露

🚨 紧急安全红色预警

2026 年 7 月 27 日，云梯指南安全响应中心（SRC）发出紧急警告：目前广泛应用于网络代理中转行业的某款开源机场前端控制面板（以 PHP-Laravel 为底层的面板系统）爆发了高危未授权远程代码执行（RCE）零日漏洞。截至今日，已有超过 100 家大中型机场的服务器后台被黑客直接攻破，包含用户明文或 MD5 加密邮箱、密码哈希值、节点订阅 Token、以及历史连接日志（含公网真实 IP）在内的庞大数据库，正被黑客打包在暗网论坛兜售并向运营者发起比特币勒索。请所有科学上网用户即刻采取自救方案！

代理加速行业因为其灰色属性，一直以来都是网络黑客攻击和“薅羊毛”产业链的重灾区。本次爆发的 0-Day 漏洞由于涉及面极广，已经导致了多达数百万普通翻墙用户的隐私信息泄露。大多数普通翻墙用户习惯在机场、论坛、甚至各大公共网站使用完全相同的电子邮箱和密码，这给了黑客极大的“撞库”空间。本文将深入还原该 0-Day 漏洞的攻击链，并为普通用户及机场站长提供全套紧急止损方案。

一、💥 面板 0-Day 漏洞的技术成因与入侵链路

根据多名机场运营团队向云梯指南反馈的数据包日志分析，这次安全漏洞主要发生在机场面板系统与第三方易支付/数字货币回调接口的交互模块中。

黑客的攻击过程可被大致解构为以下三个步骤：

  1. 第一步：绕过 API 签名校验机制。 该面板在处理第三方支付回调（Webhook）时，使用了不够安全的哈希验证函数。黑客通过特定的算法碰撞，成功伪造了已支付订单的回调请求，并在支付参数中注入了恶意的反序列化（Deserialization）Payload。
  2. 第二步：未授权远程代码执行（RCE）。 由于 Laravel 框架底层某些过时依赖包的漏洞，注入的恶意 Payload 在服务器解析回调数据包时被意外执行，导致黑客获得了服务器 Web 容器（通常为 Nginx/PHP-FPM）的控制权限。
  3. 第三步：一键脱库与植入后门。 在取得基础 shell 后，攻击者迅速执行 mysqldump 将包含用户信息的数据库整表导出至外部下载服务器。同时，黑客在节点后端对接的配置文件（如 WebAPI）中植入了流量拦截后门，用以窃取随后产生的用户流量指纹。

二、⚠️ 数据泄露对普通翻墙用户的实质性危害

在翻墙圈子中，许多用户存在安全认知盲区，认为“我只是个买流量看视频的，数据库被偷跟我没关系”。实际上，这种隐私泄漏可能给您带来以下极其严重的危害：

  • 1. 密码撞库（Credential Stuffing）： 黑客在拿到您的邮箱与密码后，会通过自动化脚本在 Gmail、Outlook、Telegram、币安、火币等金融交易所以及国内微博、淘宝等主流平台进行匹配登录。如果您的密码是同一套，黑客将直接接管您的资产和社交账户。
  • 2. 真实 IP 与上网习惯泄露： 泄露的数据库中通常记录了用户每一次与机场节点通信的“客户端公网 IP”。这意味着您在特定时间的物理定位、所使用的宽带网络运营商以及频繁访问海外网站的行为被记录在了黑客的手中，对个人隐私构成了极大的威胁。
  • 3. 订阅流量被盗刷： 每一个机场用户都有一个唯一的订阅 Token（例如 Clash 配置中的 /api/v1/client/subscribe?token=xxx）。Token 一旦泄露，黑客可以直接将其放在公开论坛或群组中当做“免费节点”供成千上万的人下载，在一夜之间刷光您的全部套餐流量。
  • 4. 精准电信诈骗与钓鱼私信： 攻击者会利用泄露的 Telegram ID 或电子邮箱，伪装成“机场客服”，声称“机场遭遇打击，现退款清算，请点击链接登记银行卡”。这是极高杀伤力的定向钓鱼攻击。

三、🛡️ 用户自救三步法：重置 Token 与密码隔离

如果您所使用的机场网站在最近 24 小时内出现异常无法打开，或者您担心自己的信息已经外泄，请立即按照以下“自救三步法”执行安全隔离：

✨ 科学上网安全自救核对清单

  1. 第一步：彻底隔离并修改常用密码
    立即前往您的常用邮箱（如 Gmail / ProtonMail），修改为一个完全独立的强密码，并强制启用两步验证（2FA / Google Authenticator）。同时，更改您在各类海内外核心服务上的相同密码。（参考 新手防割避坑安全守则）。
  2. 第二步：在机场后台重置订阅链接（Reset Token）
    登录您所购买的所有机场，进入“个人中心”或“订阅管理”页面，点击【重置订阅链接】或【Reset Security Token】按钮。重置后，旧的链接将彻底失效，黑客无法再通过已泄露的 Token 盗取您的套餐流量。随后，务必在 Clash 或 Sing-box 客户端中删除旧配置，重新导入新订阅。
  3. 第三步：警惕任何形式的退款私信与补差价通知
    请牢记，云梯指南以及任何正规机场管理层，绝不会在 Telegram 上主动发起私聊要求您输入支付验证码或银行账户进行‘余额清退’。 凡是要求您点击未知网页链接完成清算退款的，均为二次诈骗。

四、🏗️ 对机场运营站长的紧急漏洞防御建议

如果您是本漏洞所涉及面板的机场站长，我们强烈建议您采取以下安全加固动作：

  1. 第一步：下线不安全的支付插件。 暂停所有未使用预编译参数化 SQL 校验的回调接口，移除不常用的易支付网关模块。
  2. 第二步：重构敏感数据。 将机场数据库中的所有 `password` 字段哈希算法从低强度的 MD5 强制升级为带有随机盐值（Salt）的 `Argon2id` 或 `Bcrypt`，以提升防碰撞强度。
  3. 第三步：限制后端 WebAPI 对接权限。 开启双向 TLS 认证（mTLS），严格限制节点后端服务器与前端数据库接口通信的来源 IP 范围，从物理上阻止黑客横向渗透。
