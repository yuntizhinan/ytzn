网络知识普及库

理解网络代理背后的技术概念，做到心中有数

VPN

网络层全局加密工具，原用于企业远程安全访问，特征明显易被阻断。

VPS

虚拟专用服务器，用于部署个人独立代理节点，需要掌握一定的Linux知识。

节点

代理服务器端点，通过不同的国家和地区IP实现跨区域访问或流媒体解锁。

DNS

域名解析系统，解析不当可能导致DNS污染，进而造成无法代理或隐私泄漏。

网络协议

常见问题解答 (FAQ)

解答关于科学上网、机场选择与支付安全的常见疑问

1. 什么是机场？和常规VPN有什么区别？

“机场”是网民对提供Shadowsocks、V2Ray、Trojan等代理节点服务商的通称（因早期客户端如ShadowsocksR的Logo类似纸飞机）。与传统全局加密的VPN相比，机场使用的网络代理解析在应用层，支持通过分流规则实现“国内直连，国外代理”，网速更快且更省流量。

2. 应该如何选择适合自己的机场？

选择机场主要考虑三个核心因素：稳定性、速度与价格。如果对网络稳定性有高要求（如远程办公、在线会议），建议选择主打IEPL专线的机场；如果主要是娱乐看视频，则普通中转隧道即可满足要求。此外，购买时尽量遵循“月付”原则，避免年付以降低服务商跑路导致的财务损失。

3. 代理客户端这么多，我应该用哪一个？

Windows与Mac平台上，目前首选推荐使用 Clash Verge（支持Meta内核，功能丰富且更新稳定）；iOS/iPhone 平台上，Shadowrocket（俗称小火箭）最适合入门，高端玩家可以使用 Quantumult X 或 Stash；Android 平台上，Clash for Android 或 Sing-box 原生客户端是更好的选择。

4. 机场节点连接不上怎么办？

请按以下步骤排查：首先检查机场账号余额及套餐流量是否耗尽；其次，在客户端中手动触发“更新订阅”以获取最新服务器配置；然后，检查本地系统时间是否与标准北京时间同步（时间偏差超过1分钟会导致许多加密协议握手失败）；最后，尝试更换客户端的系统代理开关或更换不同的节点。
