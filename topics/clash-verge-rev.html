从零开始的 Clash Verge Rev 客户端新手安装与配置图文保姆级教程

随着经典代理工具 Clash for Windows (CFW) 的停更，基于新一代开源核心 Mihomo（原 Clash Meta 内核）的客户端——**Clash Verge Rev**，已经成为目前 Windows、macOS 和 Linux 系统平台下最强大、运行效率最高的科学上网客户端。它不仅支持最新的 Hysteria 2、Vless-Reality 等前沿传输协议，还拥有全新的 UI 界面与更低的系统内存占用。本专题将手把手带您从零开始，完整搞定其下载、配置导入、分流过滤与高级 Merge 脚本的应用。

一、 什么是 Clash Verge Rev？

Clash Verge Rev 是基于 Tauri 开发的代理工具图形客户端，其核心功能相比传统 CFW 有了质的跨越：

  • Mihomo 顶级内核： 默认搭载开源社区最活跃的 Meta 核心，完美支持 VMess, VLess (Reality), Trojan, Shadowrocket 专属节点以及下一代超高速 UDP 协议 Hysteria 2。
  • 内存消耗极低： CFW 采用 Electron 框架，运行内存常年占用 200MB 以上；而 Verge Rev 采用 Tauri 编写，日常后台挂载内存占用仅有 30MB-50MB，大幅减少了硬件资源消耗。
  • 内置更加现代化的高级控制： 方便的一键开启 Tun 网卡模式、开机自启、直观的 Merge 配置文件修改功能，极大降低了新手进阶难度。

二、 软件下载与核心系统服务安装

在开始使用前，需完成核心网络服务的部署，这也是很多新手卡关的地方：

首先，访问官方正规的 GitHub Release 页面或第三方经过安全签名的可信分发渠道下载对应的安装包（Windows 选择 `.msi` 或绿色版 `.7z`，Mac 选择 `.dmg`）。

安装完毕后打开客户端，第一步必须配置 Service Mode（系统网卡服务）。这是为了能够开启全局 Tun 虚拟网卡代理，用以接管本地游戏协议或命令行终端。点击客户端左侧的 **Settings**，找到 **Service Mode**，点击其右侧的 **Manage**，并在弹出的窗口中选择 **Install**。当指示灯从黄色变为绿色，并显示 `Active` 时，系统底层网卡接管服务即搭建完毕。

📌 核心概念提醒：

Service Mode 安装成功是开启 Tun Mode（Tun 虚拟网卡模式）的硬性前提。如果 Service Mode 安装报错，请右键选择“以管理员身份运行”客户端再次尝试。

三、 导入节点订阅与基础运行配置

配置订阅和启动代理的流程如下：

1. 获取订阅链接： 在你选购的 2026年优质高速机场 用户后台，复制对应的 Clash 订阅链接（YAML 格式）。

2. 导入配置文件： 在 Verge Rev 左侧栏点击 **Profiles**（配置），在顶部的输入框中粘贴刚刚复制的订阅 URL，随后点击右侧的 **Download**。下载完毕后，单击选定刚刚生成的卡片以激活该配置文件。

3. 选择运行模式： 点击左侧的 **Proxies**（代理），在顶部选择运行模式。推荐选择 **Rule（分流规则模式）**，系统会根据订阅内置的 IP 和域名规则，对国内常用应用执行直连，海外业务执行代理。若需要代理接管非浏览器应用（如 Telegram 软件本身、Steam 游戏联机），则需开启左侧的 **Tun Mode**（Tun 模式）。如果是低延迟节点配置需求，具体可参考专题：极低延迟游戏专用节点选择。

四、 高级 Merge 配置文件合并与脚本过滤教程

在 Verge Rev 中，不再通过 CFW 的 Mixin 来定制配置，而是采用全新的 **Merge（合并配置）** 或 **Script（扩展脚本）** 来统一接管：

若想为 AI 平台配置专门的原生 IP 节点组，可点击 **Profiles**，点击 **New**，类型选择 **Merge**。在新生成的 Merge 配置文件卡片上右键选择 **Edit**。输入如下格式的 YAML 规则，用于将特定大模型流量强行分流至支持解锁的专属节点组，如 ChatGPT/Claude防封号配置专题 所述： 

prepend-rules:
  - DOMAIN-SUFFIX,openai.com,🤖 AI专用
  - DOMAIN-SUFFIX,chatgpt.com,🤖 AI专用
  - DOMAIN-SUFFIX,claude.ai,🤖 AI专用
  - DOMAIN-SUFFIX,anthropic.com,🤖 AI专用

保存后，回到 Profiles 列表，右键点击 Merge 配置并选择 **Enable**。这样在你的主订阅更新时，分流规则依然会被自动合并，无需每次手动修改，完美实现配置的模块化与热更新。对于流媒体影音的分流解锁，可根据 Netflix/Disney+流媒体解锁 方案配置对应的 Merge 分流组。

🙋 常见问题 FAQ

Clash Verge Rev 开启 Tun 模式失败提示 'Start Tun Error' 怎么解决？ ▼
首先需要确保安装了系统虚拟网卡服务（Service Mode）。进入 Clash Verge Rev 的 'Settings'（设置），找到 'Service Mode'，点击右侧的 'Manage'，在弹出的窗口中点击 'Install'。安装完毕并显示绿色状态后，重启客户端，再点击开启 'Tun Mode' 即可成功。
为什么开启 Clash Verge 后国内很多常用软件（如微信、网易云）无法连网？ ▼
这是因为代理客户端开启了 Tun 模式但分流规则不完善，导致本地回环或国内软件数据被错误代理。建议在 'Rules'（分流模式）下运行，并在配置文件的 Merge 脚本中加入国内直连规则域名，或者开启 System Proxy 时选择 Bypass 绕过国内常用 IP。
如何实现在 Clash Verge 中对节点自动按照延迟进行排序选择？ ▼
在 'Profiles' 中下载订阅后，大多数优质机场会提供名为 'URLTest' 或 '自动选择' 的策略组。代理核心会每隔一定时间自动向特定的测速服务器发送握手包，并自动挑选出延迟最低的那个节点接管当前流量，从而达到无感秒级防故障断流的效果。
