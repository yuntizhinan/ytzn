Clash 全平台配置与订阅导入教程

作者: 发布于: 2026-07-25

在经历了多年的网络环境演变与代理协议更迭后，Clash（及其衍生内核如 Clash Meta / Mihomo）依然是 2026 年毫无争议的代理界“王者”。它凭借着极其强大的分流规则（Rule Providers）、优异的性能占用控制，以及对 Hysteria2、Vless Reality 等最新协议的完美支持，成为了高端科学上网玩家和办公人群的标配。然而，对于很多刚刚接触科学上网的新手来说，面对各种客户端、配置（Profiles）、代理组（Proxy Groups）以及不同的路由模式，难免会感到一头雾水。本篇超过 2500 字的《Clash 全平台配置与订阅导入教程》将作为您的“终极保姆级指南”，手把手带您在 Windows、macOS、Android 和 iOS 上完成所有设置，实现真正的“无感分流上网”。

如果您还没有购买可靠的节点订阅，请务必先查阅我们的 《2026年稳定高速机场推荐指南》 和最新的 机场排行榜，因为“好马配好鞍”，一个优质的机场是所有配置生效的前提。

一、核心概念科普：玩转 Clash 的三个关键词

在开始动手操作之前，我们需要先弄懂三个贯穿所有平台客户端的核心概念：

  • 1. 订阅链接 (Subscription Link)： 相当于您的“通行证”。它是机场后台提供的一串以 http 或 https 开头的网址，里面包含了成百上千个服务器节点的IP、端口和密码信息。请极其妥善地保管此链接，绝不可泄露给他人，否则您的流量将被瞬间盗刷。
  • 2. 配置文件 (Profiles)： 当你把订阅链接粘贴进软件并点击更新时，软件会从该链接下载一个后缀为 .yaml 的文本文件，这就是配置文件。它不仅包含了节点，还包含了机场主为您写好的分流规则（例如：访问百度不走代理，访问 YouTube 走代理）。
  • 3. 路由模式 (Routing Mode)： 绝大多数情况下，请永远保持在“规则模式 (Rule)”。在此模式下，软件会自动判断当前访问的网站是国内还是国外，实现国内直连加速、国外科学上网的无缝体验；如果选择“全局 (Global)”，则所有流量（包括看国内爱奇艺、打王者荣耀）都会绕道国外，不仅卡顿还会白白浪费珍贵的机场流量；“直连 (Direct)”则等于关闭了翻墙功能。

二、Windows 电脑端配置指南：首推 Clash Verge Rev

在 2026 年，曾经老旧的 Clash for Windows (CFW) 已经彻底退出了历史舞台，取而代之的是采用全新 UI 和更强大 Meta 内核的 Clash Verge Rev。它是目前 Windows 平台上体验最好、颜值最高的代理客户端。

详细导入步骤：

  1. 下载与安装： 前往 GitHub 官方仓库或通过本站提供的镜像链接，下载最新版的 Clash.Verge_x.x.x_x64-setup.exe，一路点击“下一步”完成安装并打开软件。
  2. 获取订阅： 登录您的机场官网控制台，寻找“一键订阅”或“复制 Clash 订阅链接”按钮，点击复制。
  3. 导入配置： 在 Clash Verge 界面中，点击左侧导航栏的 配置 (Profiles)。在顶部的输入框中 粘贴 刚刚复制的订阅链接，然后点击右侧蓝色的 导入 (Import) 按钮。
  4. 激活配置： 导入成功后，列表里会多出一个带有机场名字的文件。重要：必须用鼠标左键点击一下该文件，使其变为蓝色高亮（或打勾）状态，这才代表选中并激活了该配置。
  5. 开启代理： 点击左侧导航栏的 设置 (Settings)，找到 系统代理 (System Proxy) 并将其开关打开。如果需要让所有软件（如 Telegram PC版、游戏平台）都走代理，可以开启更底层的 TUN 模式 (TUN Mode)，但需要授予管理员权限。
  6. 选择节点： 点击左侧 代理 (Proxies) 面板，在上方确认模式为 规则 (Rule)。展开“节点选择”或“手动切换”策略组，挑选一个低延迟的节点即可（不知如何挑选？请看 《教你三步挑出好节点》）。

三、macOS 苹果电脑端配置指南

对于 Mac 用户，由于 M 系列芯片（Apple Silicon）的普及，客户端生态有了很大变化。我们强烈推荐使用与 Windows 端一脉相承的 Clash Verge (Mac版) 或者界面极为原生优雅的付费软件 Stash for Mac。

以 Clash Verge (Mac) 为例的配置流程：

  • 下载对应版本： 请务必确认你的 Mac 是 Intel 芯片还是 M 芯片。M1/M2/M3 等芯片必须下载 aarch64.dmg 版本，Intel 芯片下载 x64.dmg 版本。
  • 安装与授权： 将应用拖入“应用程序”文件夹。首次打开如果提示“文件已损坏或无法验证开发者”，请进入系统“系统设置 -> 隐私与安全性”，向下拉找到并点击“仍要打开”。
  • 导入与启动： 操作逻辑与 Windows 完全一致。进入 Profiles 粘贴链接导入 -> 选中该配置 -> 进入 Settings 打开 System Proxy -> 进入 Proxies 选择具体线路节点。
  • 菜单栏快捷操作： 在 Mac 屏幕顶部右上角的菜单栏中，会出现一个可爱的小猫咪图标。你可以点击它，快速进行节点切换、模式更改（Rule/Global）或一键退出。

四、Android 安卓端：多元化生态的终极选择

安卓生态相对开放，目前最流行的客户端有三款：经典开源的 Clash for Android (CFA)（部分修改版支持 Meta 内核）、冲浪板 Surfboard，以及新生代的轻量级霸主 sing-box。

📱 Clash for Android (Meta版) 极速配置指南

  1. 安装软件后打开，点击 配置 (Profiles)。
  2. 点击右上角的 + 号，选择 从 URL 导入 (Import from URL)。
  3. 在 URL 一栏粘贴机场订阅链接，名称可以随便填（如“我的机场”），然后点击右上角的“保存”图标。
  4. 等待下载完成后退回到主界面，点击灰色的 “已停止 (Tap to Start)” 按钮。如果是首次使用，系统会弹出建立 VPN 连接的权限请求，请点击“允许”。
  5. 点击 代理 (Proxies) 选项卡进入节点列表，展开对应的策略组进行节点切换。在安卓系统下拉通知栏中，可以随时查看流量消耗和进行快捷开关。

注：如果您的机场不支持最新的 Meta 协议，导致导入报错，建议您在机场后台尝试一键导入到 v2rayNG 或 Surfboard。

五、iOS 苹果端配置指南：Shadowrocket (小火箭) 称王

由于苹果 App Store 的严格审核机制，iOS 端无法下载开源的 Clash。目前统治 iOS 生态的当属大名鼎鼎的 Shadowrocket（俗称小火箭，售价 $2.99），以及完美兼容 Clash 配置文件的 Stash（售价 $3.99）。

前置条件：由于国区 App Store 下架了所有的代理软件，您必须拥有一个非中国大陆区（如美区、港区）的 Apple ID，才能在商店中搜索并购买这些软件。许多优秀的机场会在购买套餐后提供共享的海外 Apple ID 供用户免费下载。

Shadowrocket (小火箭) 导入流程：

  1. 一键导入（最推荐）： 在手机 Safari 浏览器中登录机场后台，找到“一键导入 Shadowrocket”按钮，点击后系统会自动唤醒小火箭，并提示“是否添加节点配置”，点击确定即可。
  2. 手动导入（如果一键失败）： 复制机场提供的“订阅链接”。打开小火箭，点击右上角的 + 号。在“类型”中选择 Subscribe (订阅)。将链接粘贴到“URL”框中，点击右上角的“完成”。
  3. 更新订阅： 回到首页，向右滑动刚添加的订阅名称，点击 更新 (Update)，此时会拉取最新的服务器列表。
  4. 开启与全局路由： 在首页选择一个节点（前面会出现黄色小圆点）。点击最上方“未连接”右侧的开关。首次开启需输入 iPhone 锁屏密码允许安装 VPN 配置文件。特别注意：在下方的“全局路由 (Global Routing)”选项中，务必选择“配置 (Config)”，这等同于 Clash 的 Rule 模式；千万不要选“代理 (Proxy)”，否则会导致国内App（如微信、淘宝）无法加载图片。

六、终极 FAQ：疑难杂症排查与解决

在配置过程中，新手极易遇到一些“拦路虎”，以下是本站技术团队总结的最常见问题及解决办法：

  • Q1: 为什么订阅导入成功了，节点列表也有，但是依然上不去外网？
    排查 1： 请检查你电脑/手机的系统时间是否极其准确。Clash 底层的 Vmess 和 Trojan 协议对时间校验要求极高，误差超过 1 分钟就会导致认证失败。请前往系统设置强制开启“自动同步网络时间”。
    排查 2： 检查是否被其它杀毒软件（如 360、火绒）拦截了系统代理修改。请将 Clash 添加到杀软白名单。
    排查 3： 尝试在软件中点击“延迟测试”，如果所有节点全是 Timeout，说明机场域名可能在当地被 DNS 污染了，请尝试在手机流量下重新更新订阅。
  • Q2: 开启代理后，国外的能上，但国内的某些特殊软件（如原神、企业内部OA）却断网了？
    这通常是因为有些不规范的软件不走系统的 HTTP 代理协议。解决方案是：在 Clash Verge 的设置中开启 TUN 模式，这将接管电脑的整个虚拟网卡，强制所有软件的流量都经过 Clash 规则引擎过滤。
  • Q3: 为什么看 Netflix 时总是提示使用了代理工具？我明明选了解锁节点啊。
    可能是发生了 DNS 泄露 (DNS Leak)。当你在浏览器里输入 netflix.com 时，虽然流量走了代理，但 DNS 解析却是由你本地运营商（如中国电信）完成的，Netflix 的风控系统察觉到了异常。解决方法：在浏览器的设置中关闭“安全 DNS”，或者在客户端的高级设置中启用“远程 DNS 解析”。

结语

网络代理的配置本质上就是“一条链接、一次更新、一个开关”。只要您不折不扣地按照上述图文步骤执行，理清了“订阅、配置、规则模式”的铁三角关系，无论在哪个平台都能如鱼得水。如果您已经成功配置完毕，赶快打开 YouTube 测试一下您的网速吧！想获取更多进阶玩法和极客网络知识，欢迎随时访问我们的 知识库 频道。
