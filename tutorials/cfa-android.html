Clash for Android (CFA) 完美配置指南 (含图文)

作者: 更新于: 2026-08-09

在 Android 阵营中，Clash for Android (简称 CFA) 一直是以稳定、高效且界面美观著称的“装机必备”代理软件。尽管市面上涌现了许多新星，但 CFA 凭借其对 YAML 订阅格式的完美兼容和丰富的高阶设置（如分应用代理、局域网共享），依然占据着统治地位。

本篇指南将带您从零开始，不仅完成基础的节点载入，更要教您如何榨干它的极限性能。在开始前，请确保您已经拥有了稳定可用的机场订阅链接。如果没有，请参考我们的 《2026年稳定高速机场推荐指南》。

一、下载安装与一键载入订阅

由于 Google Play 商店的地区限制，国内用户通常需要通过 APK 方式安装。

  • 第一步：下载 CFA。 请前往开源项目的 Release 页面下载最新的 .apk 文件，推荐下载 premium (高级版内核) 版本。
  • 第二步：复制订阅。 打开您的机场网站后台，点击 “一键导入 Clash”，或者手动复制 Clash 订阅链接 (YAML格式)。
  • 第三步：载入配置。 打开 CFA，点击 “配置 (Profiles)” -> 右上角的 “+” 号 -> “从 URL 下载 (URL)”。在 URL 框中粘贴刚刚复制的链接，名称 可以随意填写（如“我的机场”），最后点击右上角的保存图标。

等待几秒钟提示下载成功后，选中刚刚下载的配置文件（确保它前方有一个蓝色的圆点选中标志），然后返回主界面。

二、开启代理与分流模式选择

在主界面，点击最显眼的 “点击启动 (Tap to start)” 按钮。如果是首次启动，Android 系统会弹出一个创建 VPN 连接的警告提示，请点击“允许 (Allow)”。

切换节点与策略

启动后，点击主界面的 “代理 (Proxies)” 按钮。你会看到页面上方有三个极为关键的模式选项，强烈建议您选择“规则 (Rule)”：

  • 规则 (Rule)： 最智能的模式。根据 YAML 文件中的规则，国内 App 直连，国外 App 走节点代理。不浪费流量。
  • 全局 (Global)： 强制手机上所有的网络请求都发往国外节点。
  • 直连 (Direct)： 相当于暂停使用代理。

选好“规则”后，向下滚动，找到名为 Proxy 或 节点选择 的分组，展开后挑选一个最低延迟的国家节点即可。

三、高阶配置一：本地应用绕过 (分应用代理)

这是一个非常实用的功能。由于 Android 系统的特殊性，开启 VPN 后，有些国内银行 App 或视频 App 可能会检测到代理环境而拒绝工作，或者频繁提示“IP 异地登录”。

🛡️ 设置分应用代理 (Access Control)

  1. 回到 CFA 主界面，点击 “设置 (Settings)”。
  2. 点击 “网络 (Network)”。
  3. 找到 “访问控制 (Access Control)”，将其开关打开。
  4. 点击底部的“访问控制模式”，建议选择 “绕过 (Bypass)” 模式，然后点击下方的“绕过应用列表”，在里面勾选你所有的国内银行 App、微信、支付宝等。这样这些软件就彻底不会经过 Clash 的处理了，既省电又安全。

四、高阶配置二：局域网代理共享 (给 Switch/PS5 加速)

如果你想让家里的任天堂 Switch、PS5 游戏机，或者不支持安装代理软件的智能电视也能翻墙看 Netflix，你可以把安装了 CFA 的手机当作一台“代理路由器”。

  • 手机端设置： 在 CFA 主界面，点击“设置” -> “网络”，找到 “允许局域网连接 (Allow LAN)” 并开启。记下页面上显示的端口号（通常是 7890）。然后进入手机系统的 WiFi 设置，查看当前手机的局域网 IP（例如 192.168.1.105）。
  • 设备端设置（如 Switch）： 将 Switch 连入与手机相同的 WiFi。在 Switch 的网络高级设置中，将 代理服务器 (Proxy) 设为开启，服务器填写手机的 IP 192.168.1.105，端口填写 7890。保存后，你的游戏机就能畅游国际网络了！

结语

Clash for Android 凭借其高度的可玩性和扎实的底层架构，一直是安卓极客的不二之选。合理利用分应用代理，能让你的手机电池续航大幅提升。
