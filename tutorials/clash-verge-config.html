Clash Verge 配置教程：系统代理、规则与故障排除

作者: 云梯指南编辑部 $12026-09-08

摘要：本文为您提供详细的 Clash Verge 进阶配置教程。重点介绍系统代理、TUN 模式的区别与开启条件，并深入解析 Profiles、Proxies、Rules 及基础 DNS 的设置方法，帮助您排查常见的网络连通性问题。

如果您只想快速解决

如果您已经安装并导入了配置，但仍然无法科学上网，可以优先检查以下 4 步：

  1. 确认已经在 Profiles 中选中了正确的配置文件，并显示绿色。
  2. 进入 Proxies，确认上方选定的是规则（Rule）模式而非直连（Direct），并选择一个未超时的节点。
  3. 在设置中开启 系统代理 (System Proxy)。
  4. 如果仍无网络，尝试开启 TUN 模式（需要管理员或 Root 权限）以接管全局流量。

问题背景

许多用户在参考了基础的Clash Verge 使用教程并成功导入节点后，仍然会遇到各种局部网络不通或软件冲突的问题。本教程旨在从更深层次为您梳理 Clash Verge 的核心组件，带您理解数据是如何流转的。

一、系统代理 (System Proxy) 与 TUN 模式

这是决定您的流量是否经过代理的最核心开关。

1. 系统代理 (System Proxy)

什么是系统代理： 开启后，Clash Verge 会向 Windows/macOS 操作系统注册一个本地 HTTP/SOCKS 代理端口。大部分常规软件（如浏览器）会自动遵循操作系统的代理设置。

适用场景： 绝大多数网页浏览、日常办公软件。开启简便，无需高级权限。

常见问题： 浏览器如果安装了类似 SwitchyOmega 的插件，可能会覆盖系统代理。您可以暂时禁用插件进行排除。

2. TUN 模式 (虚拟网卡)

什么是 TUN： 开启后，Clash Verge 会在系统中创建一张虚拟网卡，强制接管本机所有的网络流量（包括不支持设置代理的游戏、终端命令、UWP 应用等）。

适用场景： 游戏加速、命令行工具下载、遇到系统代理失效的特殊情况。

注意事项： 开启前需要提供 Administrator（Windows）或 Root（macOS）权限。

二、Profiles 与 Proxies 设置

Profiles (配置管理)

这里管理您所有的配置文件。您可以同时存在多个机场的配置。在使用前，必须右键某一个配置项并选择 Use (使用)。详细的添加与更新方法，可以参考我们的Clash Verge 导入配置指南。

Proxies (代理节点)

这里决定了当前流量通过哪台服务器转发。

  • Rule (规则模式)： 推荐模式。国内网站直连，被屏蔽的网站走代理节点。
  • Global (全局模式)： 无论国内外网站，所有流量一律走代理节点。适合排查规则导致的网络不通问题。
  • Direct (直连模式)： 相当于关闭了翻墙功能，所有流量不经过代理服务器。

三、Rules (路由规则) 与基础 DNS

Rules： Clash 会根据配置内设定的规则（如域名后缀、IP 范围）决定每个请求的去向。如果您发现某个特定海外网站打不开，可以在日志中查看它命中了哪条规则，是否被误判为了 Direct。

DNS： Clash 内部拥有自己的 DNS 解析模块以防止 DNS 污染。正常情况下，机场提供的配置已经包含了合理的 DNS 规则。普通用户不需要手动修改，如果遇到 DNS 解析失败，建议优先切换节点或联系机场客服。

验证配置结果

完成所有操作后，可以在浏览器的隐私模式下打开 Google。如果能正常访问，进入 Clash Verge 的 Logs (日志) 页面，您应该能看到对应域名的连接记录，显示其命中了哪条规则并分配给了哪个代理节点。

常见 FAQ

1. Clash Verge 开启系统代理后浏览器还是直连怎么办？

常见原因之一是浏览器安装了其他代理切换插件。您可以优先检查扩展管理，暂时关闭 SwitchyOmega 等插件后重试。

2. Clash Verge TUN 模式什么时候需要开启？

当您需要为终端软件（CMD/Terminal）、特殊 UWP 应用、或部分不支持系统代理的游戏提供代理环境时，建议开启 TUN 模式。

3. 规则模式 (Rule) 和全局模式 (Global) 哪个更好？

日常使用推荐 Rule 模式，可以在访问国内网站时保持低延迟和节省代理流量。Global 仅在某些非常小众的网站被误判直连时临时使用。

4. 日志里显示 Direct 是什么意思？

这表示根据当前的 Rules 设置，该请求被判定为无需代理，流量直接通过本地网络发往目标服务器。
