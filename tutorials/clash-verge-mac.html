Clash Verge for Mac 配置指南 (含图文)

作者: 发布于: 2026-08-09

对于使用 macOS 的苹果电脑用户而言，在经历了 ClashX 停更的风波后，Clash Verge Rev 无疑是 2026 年最完美的接班人。它不仅完美兼容苹果最新的 M 系列芯片（Apple Silicon）和老款 Intel 芯片，还拥有与系统高度一致的极简 UI 设计和强大的 Meta 协议解析能力。

本篇教程将带你零基础完成 Mac 端 Clash Verge 的下载、安全授权、一键系统代理设置与分流规则管理。在开始前，请确保您已经拥有了稳定可用的机场订阅链接。如果没有，请参考我们的 《2026年稳定高速机场推荐指南》。

一、极度重要：认准芯片型号下载安装包

Mac 电脑目前存在两种不同架构的芯片，下载错误的安装包会导致软件闪退或疯狂占用 CPU。请先点击屏幕左上角的苹果图标 ()，选择 “关于本机”，查看“芯片”或“处理器”一栏：

  • 如果是 Apple M1/M2/M3/M4： 必须下载名称中带有 aarch64.dmg 的安装包（ARM 架构原生版）。
  • 如果是 Intel Core (如 i5, i7, i9)： 必须下载名称中带有 x64.dmg 的安装包。
  • 前往开源仓库下载完毕后，双击 .dmg 文件，将 Clash Verge 的图标拖动到右侧的 Applications (应用程序) 文件夹中即完成安装。

二、解决“文件已损坏”的安全警告 (Mac 新手必看)

由于 macOS 的 Gatekeeper 安全机制，当你第一次打开从网上下载的 Clash Verge 时，系统极有可能会弹出一个吓人的警告框：“Clash Verge 已损坏，打不开。您应该将它移到废纸篓。”

请不要恐慌，也不要移到废纸篓！这是苹果的安全限制机制。解决方法如下：

  1. 点击弹窗上的“取消”。
  2. 打开 Mac 的 “系统设置 (System Settings)” -> “隐私与安全性 (Privacy & Security)”。
  3. 向下滑动，找到安全性板块。你会看到一行字提示“已阻止使用 Clash Verge，因为来历不明”。
  4. 点击旁边的 “仍要打开 (Open Anyway)” 按钮。在输入你的 Mac 锁屏密码或指纹验证后，软件就可以正常启动了。

三、导入订阅与分流规则设置

软件启动后，你会在屏幕顶部的菜单栏看到一只“可爱的小猫咪”图标。点击它，选择 “打开面板 (Dashboard)” 进入主界面。

1. 导入配置

  • 登录你的机场网站，点击 “复制 Clash 订阅链接”。
  • 在 Clash Verge 主界面的左侧点击 “配置 (Profiles)”。
  • 在顶部的输入框 ⌘(Command) + V 粘贴链接，点击右侧的 “导入 (Import)”。
  • 关键步骤： 下载完成后，列表里会出现一张卡片。务必用鼠标左键单击一下这张卡片，使其背景变成高亮色或出现打勾图标，此时右下角会弹出提示“配置切换成功”。

2. 设置分流规则 (Proxy Groups)

点击左侧的 “代理 (Proxies)” 选项卡。页面最上方请确保选中 “规则 (Rule)” 模式（这是实现国内直连、国外代理自动分流的基础）。

在下方的列表中，你会看到名为 Proxy 或 手动选择 的策略组。展开它，挑选一个低延迟的地区节点（例如“香港专线”）。你甚至可以点击右上角的“雷达”图标进行一次全面的延迟测试。

四、一键系统代理与增强模式 (TUN)

常规网页浏览：开启系统代理

点击左侧的 “设置 (Settings)” 面板，找到 “系统代理 (System Proxy)”，将右侧的开关打开。此时，你就可以使用 Safari 或 Chrome 浏览器流畅访问 Google 和 YouTube 了。

🚀 进阶必学：开启 TUN 模式接管所有软件

如果你发现 Telegram、Discord 或终端终端命令 (Terminal) 无法连网，说明它们不走系统的 HTTP 代理。此时你需要开启底层的 TUN 模式：

  1. 在 “设置 (Settings)” 面板的顶部，找到 “Verge 守护进程 (Verge Helper)”。点击它右侧的“授权 (Authorize)”，按提示输入 Mac 开机密码。
  2. 授权成功后，向下滚动找到 “TUN 模式 (TUN Mode)”。
  3. 将其开关打开。一旦开启，Mac 上所有的软件流量都将被强制过滤与代理，实现真正的 100% 科学上网。

结语

Mac 平台的 Clash Verge Rev 无论是颜值还是性能，都已经做到了极致。利用好它的顶部状态栏快捷菜单，你可以一键完成网络模式的切换而无需频繁打开面板。

如果您在配置完成后仍遇到部分网站无法打开、时间不同步或 DNS 问题，欢迎查阅我们的 科普知识库。希望这篇为 Mac 用户量身打造的教程，能为您带来最完美的数字冲浪体验！
