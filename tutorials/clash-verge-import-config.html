Clash Verge 导入配置教程：如何添加和使用代理配置

作者: 云梯指南编辑部 $12026-09-08

摘要：本文详细介绍如何在 Clash Verge 中导入订阅链接与本地配置文件。灵活掌握添加、使用和更新代理配置的方法，是保持节点可用性的核心步骤，也是解决部分节点连接错误的基础。

如果您只想快速解决

如果您已经拿到了服务商提供的订阅链接，仅需几步即可完成导入：

  1. 在 Clash Verge 左侧导航栏点击 Profiles (配置)。
  2. 在页面顶部的输入框中粘贴您的订阅链接 (URL)。
  3. 点击旁边的 Import (导入) 按钮。
  4. 等待列表刷新，右键点击新出现的配置项并选择 Use (使用)。
  5. 进入 Proxies (代理) 页面测试节点连通性。

问题背景

无论是初次使用，还是之前的配置失效，如何将新的代理线路信息载入到客户端中都是必须要掌握的技能。通常服务商会提供一个“订阅链接”，有时也会提供单体的 YAML 配置文件。本篇着重解决如何在不同场景下顺利将它们导入到 Clash Verge 中。

方式一：通过订阅 URL 导入 (推荐)

绝大多数情况下，使用订阅 URL 是最便捷的方法，因为它可以让您直接在客户端内更新所有节点信息。

  1. 从您的机场或服务商后台，复制适用于 Clash 格式的订阅链接。
  2. 打开 Clash Verge，点击 Profiles (配置)。
  3. 将链接粘贴到顶部的 URL 输入框内。
  4. 点击 Import (导入)。软件会向该链接发起请求并下载配置文件。
  5. 下载成功后，列表中会多出一条记录。必须右键或点击该记录，选择 Use (使用) 才能使其生效。
  6. 进入 Proxies 界面，检查节点是否已正常加载。

方式二：通过本地文件导入

在某些网络环境下，由于订阅链接被阻断，您可能只能从服务商处下载一个 `.yaml` 或 `.yml` 结尾的配置文件存放在电脑中。

  1. 在 Profiles (配置) 页面，点击顶部输入框右侧的 New (新建) 或相应的添加文件按钮（具体取决于您的 Clash Verge 版本界面）。
  2. 选择类型为 Local (本地)。
  3. 浏览并选择您下载好的 `.yaml` 配置文件。
  4. 导入后，同样需要在列表中右键选择 Use (使用)。

配置更新与常见失败排查

订阅节点的可用性会随时间变化，因此需要定期更新配置。

  • 手动更新： 在已导入的配置记录上右键，选择 Update (更新)。
  • 自动更新： 在配置记录上右键选择 Edit (编辑)，可以找到 Update Interval 选项，填入 24，则每 24 小时会在后台自动更新。

如果您遇到了导入或更新失败，可以优先检查以下几点：

  • 检查链接格式： 某些机场需要提供专为 Clash 准备的链接，SSR 或 v2ray 原生链接可能无法直接解析，会导致配置为空或报错。
  • 检查网络环境： 首次导入订阅时如果被墙阻断，可能需要依靠浏览器临时代理环境获取更新。或向服务商索要国内备用链接。
  • 文件损坏： 对于本地导入，确保 `.yaml` 文件格式完好，没有在传输中出现乱码。

如果配置导入成功但节点依然全红，请参考节点连接失败排查教程做进一步分析。

常见 FAQ

1. Clash Verge 为什么导入订阅失败？

常见原因之一是网络层面的阻断。服务商提供的订阅域名本身可能无法直接连接，建议联系服务商获取备用订阅地址。

2. Clash Verge 为什么导入后没有节点？

可能与订阅链接格式有关。如果您使用了不兼容 Clash 架构的订阅源，解析出来的文件内容会无法被识别，导致 Proxies 页面空白。

3. 本地配置文件导入后如何更新节点？

本地配置文件无法直接通过点击 Update 按钮来拉取新节点信息，您必须重新向服务商下载最新的 `.yaml` 文件并再次进行本地导入替换。

4. 导入时提示 YAML Parse Error 是什么意思？

这意味着下载到的配置文件结构错误或存在非法字符，往往发生于服务商下发的配置模板不支持您当前使用的内核版本（如 Meta 内核专属字段）。
