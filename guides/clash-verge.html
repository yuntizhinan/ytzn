Clash Verge 核心教程

在目前的科学上网与网络分流生态中，基于 Rust 和 Tauri 框架开发的 Clash Verge Rev 已经毫无争议地成为了新一代代理客户端的主力军。随着经典工具 Clash for Windows 与 ClashX 逐渐退入历史舞台，搭载 Mihomo (原名 Meta) 内核 的 Clash Verge Rev 不仅具备极低的内存与 CPU 开销，更在原生层面解锁了对 Vless、Reality、Hysteria 2 以及 TUIC 等新一代抗审查出海协议的支持。

然而，许多用户虽然下载了软件，但由于对其底层的 Meta 配置规则、DNS 分流逻辑以及本地驱动接管原理了解不深，常常遇到“无法完美解锁 ChatGPT 区域风控”、“本地命令行流量未被正确接管”或“机场更新订阅后本地自定义规则失效”等问题。本教程将由浅入深，从架构版本选择、订阅同步、代理策略管理，到核心的高阶配置合并（Merge）与服务模式（Service Mode），为您提供保姆级核心指南。

一、Clash Verge Rev 版本的选择与安全获取

在安全防范极其严密的 2026 年，请务必从官方维护的 Github Releases 仓库获取安装包，警惕任何内嵌第三方推广的非官方修改版。

软件安装包版本识别

  • Windows 平台：
    • Clash.Verge_x.x.x_x64-setup.exe：标准安装版本（推荐普通用户，内置系统服务）。
    • Clash.Verge_x.x.x_x64_portable.zip：便携免安装绿色版（解压即用，配置保存在当前文件夹）。
  • macOS 平台：
    • Clash.Verge_x.x.x_x64.dmg：适用于旧款 Intel 芯片麦金塔电脑。
    • Clash.Verge_x.x.x_aarch64.dmg：适用于 Apple Silicon 芯片（M1/M2/M3系列）Mac。
  • Linux 平台：提供 .AppImage 及 .deb 包，主要适配各大现代发行版。

二、核心步骤：订阅配置与运行管理

激活客户端的第一步，是将我们在服务商（如 快狸机场 等）处购买的订阅链接安全导入客户端中。

1. 订阅链接一键同步

  1. 登录您的翻墙服务商面板。例如，使用纯净住宅 IP 与原生 Vless 协议的 快狸机场，在后台选择“复制 Clash 订阅”或使用内置的“一键配置导入”。
  2. 打开 Clash Verge Rev，点击左侧导航栏的 订阅 (Profiles) 面板。
  3. 在顶部的 URL 输入框内粘贴您复制的机场订阅链接。
  4. 点击 导入 (Import)。软件会利用本地 HTTPS 模块抓取 YAML 配置文件。
  5. 右键点击导入的配置卡片，选择 编辑信息 (Edit Info)：
    • 名称 (Name)：重命名为识别性强的标识，如 快狸机场。
    • 自动更新 (Auto Update)：建议填入 24（单位为小时，代表每隔 24 小时自动向服务器抓取最新的规则与节点拓扑）。
  6. 双击这块配置卡片（或者单击使其边框显示高亮深绿色），即代表激活当前订阅。

2. 启动代理与模式切换

进入左侧 设置 (Settings) 面板，确认首选内核为 Mihomo (Meta)。回到主界面，开启 系统代理 (System Proxy) 开关。此时，Windows 代理设置中会被自动注入本机的 Loopback 回环地址和端口（默认 127.0.0.1:7890）。

在左侧 代理 (Proxies) 面板顶部，您可以自由切换代理模式：

  • 规则模式 (Rule)：智能分流模式。Clash 内核会识别流量的目的 IP 或域名。如果是国内网站，流量直连发送；如果是国外网络，则流向您在策略组里选取的代理节点。
  • 全局模式 (Global)：强制所有出站流量均通过机场代理。
  • 直连模式 (Direct)：所有流量直接访问，不经过任何翻墙隧道。

三、高阶进阶：配置合并 (Merge) 机制与 YAML 代码自定义

在传统客户端中，想要增加自定义分流规则，我们必须使用极其复杂的配置预处理器。而 Clash Verge Rev 引入了极其先进的 扩展配置 (Merge) 机制。它允许我们通过编写一段简洁的 YAML 配置，以“合并（叠加）”的形式对导入的机场订阅配置进行改写，从而彻底避免了订阅更新时本地自定义参数被冲刷覆盖的问题。

1. 新建本地合并扩展

  1. 点击左侧导航栏的 订阅 (Profiles) 面板。
  2. 点击右上角的 新建 (New)，在弹出的类型选择中选择 Merge (合并)。
  3. 在新出现的扩展卡片上右键点击，选择 编辑文件 (Edit File)。
  4. 在文本编辑器中编写您的自定义覆盖逻辑，例如下面这套高阶 DNS 与特定分流的复合 YAML 配置： 
    prepend-rules:
  # 强制使本地开发或局域网段全部直连
  - DOMAIN-SUFFIX,local,DIRECT
  - IP-CIDR,192.168.0.0/16,DIRECT
  # 将 ChatGPT 强制分流至名为 🤖 ChatGPT 的策略组
  - DOMAIN-SUFFIX,openai.com,🤖 ChatGPT
  - DOMAIN-SUFFIX,anthropic.com,🤖 ChatGPT
  - DOMAIN-SUFFIX,claude.ai,🤖 ChatGPT

dns:
  enable: true
  ipv6: false
  enhanced-mode: redir-host
  nameserver:
    - 223.5.5.5 # 国内主解析采用阿里云 DNS
    - 119.29.29.29
  fallback:
    - https://dns.cloudflare.com/dns-query # 境外 DNS 采用 HTTPS 加密查询，杜绝本地污染
    - https://dns.google/dns-query

2. 激活 Merge 扩展

编写完成并保存后，回到 Profiles 列表。右键点击刚才新建的 Merge 卡片，选择 启用 (Enable)。再次双击您的主力机场订阅（如快狸订阅），Clash Verge 就会在后台自动将这两个配置进行原子级的逻辑拼接，您的自定义规则和 DNS 配置将永远处于优先级最高的置顶状态。

四、Wintun / 网卡级 TUN 模式的深度配置

系统代理虽然能够完美接管绝大多数基于 Web/IE 代理协议的客户端，但针对没有代理配置选项的各类国产办公软件、Steam/Origin 联机网络游戏、命令行终端（CMD, PowerShell, Git Bash）以及各类 Windows UWP 应用是无能为力的。

为了实现真正的系统级网卡流量完全劫持，必须开启 TUN 模式：

  1. 启用授权服务：进入 设置 -> 应用设置 -> 服务模式 (Service Mode)。点击其右侧的 安装 或 启用（此时需要提供 Windows 账户的 UAC 系统管理员授权）。成功后，服务模式会显示状态为 已激活（地球图标变成绿色）。
  2. 下载内核接口驱动：确保安装了最新的 Wintun.dll 网卡网关驱动程序。
  3. 开启 TUN 模式：回到主界面或设置选项，打开 TUN 模式 (Tun Mode) 开关。
  4. 验证网卡状态：打开 Windows 进程或命令提示符，输入 ipconfig，若能看到一个名为 Clash 或 wintun 虚拟网卡的 IPv4 地址分配，即代表整机的所有底层网络收发已经被 Clash Verge Meta 内核完美接管。

五、精选机场服务搭配与分流排障

无论是 TUN 模式还是 YAML 配置，都需要底层接入高质量、高吞吐的物理节点才能发挥出最好的性能：

  • 对于高码率流媒体播放与轻度网页办公，支持全线原生 Vless 协议与极低资费门槛的 快狸机场 是当前高性价比的优质伴侣。
  • 如果您在跨境办公中对连接稳定性有绝对刚性要求，可重点考量接入物理内网隔离专线、全 1.0 倍率诚实计费的 光年梯 以及支持无限设备数、晚高峰丢包几乎为零的 极连云 深度评测。
  • 若在使用中遇到节点超时（Timeout）或无法联通：
    1. 请第一步核对您本机的系统时间是否与标准北京时间一致（偏差大于 60 秒将导致双边安全协议密钥验证失败）。
    2. 可以在 Verge 的 连接 (Connections) 面板中，实时观测网络连接请求的流向、具体分流规则匹配结果（究竟是 Rule DIRECT 还是 Rule Proxy），这是极客排障的最强利器。
