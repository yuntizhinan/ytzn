Sing-box 手机端教程

✍️ 作者: 技术编辑部 ⏱️ 阅读时长: 7 分钟 📅 发布于: 2026-07-10 🔄 更新于: 2026-08-01

在移动端代理工具生态中，尽管 iOS 平台拥有 Shadowrocket、Quantumult X 等经典付费应用，Android 平台拥有 v2rayNG 与 Clash Meta 等工具，但进入 2026 年，一个全新的跨平台开源神器——Sing-box 正在以势如破竹的态势席卷移动端。

不同于以往各平台客户端内核各异的局面，Sing-box 实现了 iOS (Sing-box for iOS / SFI) 与 Android (Sing-box for Android / SFA) 底层内核与配置文件（JSON）的高度统一。最重要的是，作为支持原生 Vless (Reality)、Hysteria 2 和 TUIC v2 等前沿出海协议的官方客户端，它在 iOS App Store 完全免费！本教程将由浅入深，从双系统客户端安全下载、JSON 订阅一键同步、分流模式切换，到安卓电池优化防杀后台、iOS 锁屏防断流等移动端高频痛点，为您提供保姆级使用指南。

一、双系统客户端的正确获取与下载

为了防范被植入木马或带有强制广告的非官方包，请务必通过如下安全官方渠道获取 Sing-box 手机端：

1. iOS (iPhone/iPad) 平台

  • 获取方式：登录非中国大陆区的 Apple ID（如美区、港区），直接在 App Store 搜索 sing-box（认准开发者为 Nekotaro，图标为带线条构成的抽象盒子图案）。
  • 优势：它是完全免费的，完美调用 iOS 系统的 Network Extensions 原生网卡服务。在 iPhone 15/16 等现代架构芯片上运行内存占用仅为十几兆，是目前最省电的 iOS 代理客户端。

2. Android 平台

  • 获取方式：首选 Google Play 商店下载；无 Google 服务的设备，可直接访问 Sing-box 的 GitHub 官方 Releases 仓库，下载对应的 SFA-x.x.x-arm64-v8a.apk 安装包。

二、保姆级配置实战：JSON 订阅一键同步

目前，包括以原生住宅 IP 和 Vless 协议著称的 快狸机场 以及支持不限设备数的 极连云 在内的主流高质量机场，均已在后台原生集成了“Sing-box 订阅链接”。

1. iOS 手机端配置步骤 (SFI)

  1. 登录您的机场后台，复制 Sing-box JSON 订阅地址。
  2. 打开 SFI 客户端，点击底部的 Profiles (配置文件) 选项卡。
  3. 点击右上角 + (新建) 按钮：
    • Name：填写机场名称，例如 快狸机场。
    • Type：切换为 Remote (远程)。
    • URL：粘贴您刚才复制的 JSON 订阅链接。
    • Update Interval：填入 24（单位为小时，代表每 24 小时在后台同步更新一次节点配置）。
  4. 点击右下角 Create。拉取完成后，点击卡片使其边缘泛出绿色高亮（选中该配置）。
  5. 回到 Dashboard (仪表盘) 首页，点击 Enable (启用)，在系统弹出的“VPN 连接请求”中点击“允许”，输入手机解锁密码授权即可。

2. Android 手机端配置步骤 (SFA)

  1. 复制机场 Sing-box JSON 订阅地址。
  2. 打开 SFA 客户端，点击底部的 Profiles。
  3. 点击右上角 + 按钮：
    • Name：输入 极连云专线。
    • Import Type：选择 Remote (远程链接)。
    • URL：粘贴订阅地址。
  4. 点击保存。在配置列表中选中新生成的卡片。
  5. 回到 Dashboard，点击 Start (启动)。安卓系统会弹出“网络连接请求”确认，点击确定即可。

三、代理策略组与分流运行模式选择

启动连接后，点击底部的 Groups (策略组) 或 Dashboard 选项卡，即可切换运行模式：

  • Rule (分流规则模式 - 推荐)：Sing-box 会解析 JSON 配置里的规则集。国内流量（如微信、淘宝、高德地图）直接走本地直连，出海流量（如 YouTube、Wikipedia）则交由代理节点。
  • Global (全局代理模式)：无视路由分流，全机流量强制通过选定的特定节点出海。适用于临时风控自查。在此模式下，如需流畅访问 ChatGPT 等风控严格的 AI 平台，推荐使用 极连云 或 快狸机场 提供的纯净原生住宅 IP 节点，以防止账户被判定异地登录。
  • 节点测速：点击策略组右上角的“闪电”测速图标，即可针对组内节点发起并发心跳测试。数值越小，代表握手延迟越低。

四、极客优化：Sniff 流量嗅探与 Android 应用分流

Sing-box 手机端的高级性能优化，主要集中在 DNS 策略与应用控制上：

  1. 开启 Traffic Sniffing (流量嗅探)：在 Sing-box 导入的 JSON 配置文件中，入站模块默认开启了嗅探。这保证了即使本地系统 DNS 被宽带运营商投毒，Sing-box 也能通过提取网络请求中的真实 SNI 域名匹配正确的路由规则，大幅减少因 DNS 泄露引起的断连。
  2. Android 专属：应用分流控制（App Control）：在 Android 端的设置中，可以进入 设置 -> 应用控制 (App Control)，启用并选择“仅代理选定应用”，将 Chrome、Telegram 等真正需要出海的应用加入名单，而让微信、支付宝等国内应用完全绕过 VPN，这能为安卓手机节省大量处理芯片加解密的功耗，极大提高电池续航。

五、移动端痛点排除：安卓后台常驻与 iOS 锁屏断连

手机端最大的痛点是“后台静默掉线”或“锁屏后网络断开”，这在双系统中有不同的优化手段：

1. 安卓手机防杀后台（Battery Optimizations）

安卓系统默认有极其激进的进程回收机制，必须进行三步锁死：

  • 开启自启动权限：在手机系统 设置 -> 应用管理 -> 自启动管理，允许 Sing-box 自启动和关联启动。
  • 电池优化白名单：前往手机 设置 -> 电池 -> 应用电池管理 -> 电池优化，将 Sing-box 设为“无限制（允许后台高功耗常驻）”。
  • 后台锁定卡片：呼出多任务管理页面，按住 Sing-box 向上拖动或点击锁头图标锁定卡片，防止被一键清理。

2. iOS 手机锁屏断连自查

SFI 利用的是 iOS 底层原生 VPN 网卡接口，锁屏断连 99% 的原因在于您选定的节点稳定性差导致心跳超时，iOS 为了省电会自动挂起没有网络活动的 VPN 隧道。

建议使用稳定度高、晚高峰丢包低的 IPLC 物理专线节点（如 光年梯 专线），确保后台心跳包持续活跃，即可彻底杜绝锁屏挂起的问题。

六、物理专线推荐与日志排障面板

配置好移动端 Sing-box 后，出海链路的性能依旧取决于机场线路质量：

  • 针对日常追剧、超高吞吐 4K 播放场景，推荐选用全 1.0 倍率、原生支持 Vless/Trojan 协议的低价高性能服务 快狸机场。
  • 若对晚高峰物理延迟与抗抖动有极高要求，可参考接入物理内网隔离专线的 光年梯 以及支持不限在线设备数、针对各类跨境 AI 服务进行出口优化住宅 IP 的 极连云 深度评测。
  • 若在日常运行中遇到问题，可点击主界面的 Logs (日志监视器)，实时观测解析状态与请求流向，即可秒级锁定并解决所有规则冲突。
