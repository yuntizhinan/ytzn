Stash 客户端配置教程

✍️ 作者: 技术编辑部 ⏱️ 阅读时长: 7 分钟 📅 发布于: 2026-07-10 🔄 更新于: 2026-08-01

在苹果 iOS 系统的科学上网生态中，大部分用户熟知 Shadowrocket（小火箭）的易用性。然而，对于习惯了在 Windows 或 Mac 端使用 Clash Verge、Clash for Windows 规则分流的用户而言，寻找一款在 iOS 端能够 直接无缝读取 Clash YAML 配置文件 的客户端是绝对的刚需。这就是 Stash。

Stash 被官方定位为“Clash for iOS”的最佳物理适配工具。它不仅在原生层面完整兼容 Clash 的所有配置文件语法、规则组（Rule Providers）和策略组（Policy Groups），更在此基础上引入了更符合 iOS 触控习惯的可视化操作控制台、本地 HTTPS 解密（Mitm）、JavaScript 脚本重写以及本地加密 DOH 分流模块。本教程将由浅入深，从安全购买下载、Clash 订阅同步导入、分流模式管理，到核心的根证书系统级完全信任、Override（覆盖重写）模块以及本地域名防劫持调优，为您提供详尽配置指南。

一、Stash 客户端的安全获取与防坑指南

Stash 是一款付费的 iOS 网络代理扩展工具，由于监管政策原因，已在国区 App Store 下架，请按照如下流程下载正版：

  1. 准备非中国大陆区的 Apple ID：推荐使用自己注册的美区或港区 ID，在 App Store 退出国区账号后登录。
  2. 下载正版：在 App Store 搜索 Stash（认准带淡绿色折纸立体图标，开发者为 Stash Networks Limited）。软件官方售价为 3.99 美元。
  3. 充值与防骗：购买海外苹果 Gift Card（礼品卡）充值到余额中进行购买。请勿购买来路不明的共享账号，防止导致应用闪退、无法更新，或因共享账号锁死导致手机被远程锁定。

二、保姆级配置实战：Clash YAML 订阅导入

Stash 的核心优势在于它不需要繁琐的“订阅转换”。市面上几乎所有的优质机场服务商（如以大带宽住宅 IP 著称的 快狸机场 与支持企业专线 IPLC 的 极连云）提供给您的 Clash YAML 订阅链接，在 Stash 中都可以直接导入使用：

  1. 获取机场订阅：登录您的科学上网服务后台，找到一键订阅，复制 Clash 订阅链接。
  2. 在 Stash 中新建配置：
    • 打开 Stash，点击底部菜单栏的 配置 (Profiles)。
    • 点击右上角的 + (新建) 按钮。
    • 在新建配置菜单中选择 从 URL 下载 (Download from URL)。
    • 参数配置：
      • URL 栏：直接粘贴刚才复制的 Clash 订阅地址。
      • 名称 (Name)：重命名为识别性强的标识，如 快狸机场。
  3. 点击右上角的 下载 (Download)。Stash 内置的 YAML 解析引擎会自动拉取并编译订阅文件，生成对应的策略组与节点卡片。
  4. 激活配置：在配置列表中，轻触选中这块新导入的配置卡片，使其左侧泛出淡绿色圆点，代表已激活启用。

三、代理模式切换与可视化控制台

回到 Stash 的 首页 (Dashboard)，点击右上角的 启动 (Start) 开关。系统首次会弹出“Stash 想要添加 VPN 配置”的警告。点击 允许 (Allow) 并提供 Touch ID 或手机锁屏密码进行管理员授权。

在主界面上方，您可以轻松切换以下三种运行模式：

  • 规则分流 (Rule)：智能分流模式。国区流量直接直连，不走代理；出海流量则分流至对应节点。如果某些特定服务（如 OpenAI）需要特定的落地 IP，可以利用规则将流量映射至特定原生住宅 IP 节点下（具体的专线与 AI 出口解锁思路，也可参考不限在线设备数的 极连云）。
  • 全局代理 (Global)：强制所有出站流量强行通过您选定的特定节点，常用于临时调试。
  • 直接连接 (Direct)：关闭代理网络，直接用本地物理链路连接，相当于直连。

四、极客进阶：MITM 中间人解密与本地根证书信任

为了实现类似 Surge 的脚本重写、网页内嵌广告强力过滤拦截等高级功能，Stash 必须被授权能够对特定 HTTPS 流量进行本地解密（MitM）。如果开启了去广告模块却未激活根证书，系统会弹出严重的 HTTPS 访问异常警告。

请按照以下三个步骤，一步不落地完成 CA 根证书的系统级完全信任：

第一步：本地生成根证书

  1. 在 Stash 底部点击进入 设置 (Settings)，向下滑动找到 HTTPS 解密 (MitM)。
  2. 打开 HTTPS 解密 开关，并点击 生成 CA 证书 (Generate CA Certificate)。
  3. 根证书在手机本地安全生成后，点击 安装证书 (Install Certificate)。系统会自动唤醒 Safari 浏览器并下载描述文件，在弹窗中点击 允许。

第二步：安装配置描述文件到 iOS 系统

  1. 打开 iPhone 手机系统的 设置。
  2. 在最上方会多出一个 已下载描述文件 (Profile Downloaded) 选项，点击进入。
  3. 点击右上角 安装 (Install)，输入锁屏密码并确认。

第三步：激活系统级“完全信任根证书”

  1. 依次进入系统 设置 -> 通用 (General) -> 关于本机 (About)。
  2. 向下滑动至底部，进入 证书信任设置 (Certificate Trust Settings)。
  3. 在“针对根证书启用完全信任”列表中，找到刚刚安装的 Stash CA 证书，打开其右侧的绿色信任开关，并在弹出的警告中确认信任。

此时，HTTPS 解密通道已经彻底打通。配合 Stash 底部的 覆盖 (Override) 机制，您可以一键导入去广告、免抜卡解锁特定应用等模块，无缝载入。

五(")-DNS 覆盖调优与流量嗅探功能

iOS 系统在移动网络与 WiFi 切换时极易发生本地域名解析污染，这会导致即便连接了节点，网页依旧卡死。

  1. DNS 覆盖设置：在 Stash 设置 -> DNS 面板下开启 DNS 覆盖 选项。配置国内主解析组为腾讯公共 DNS (119.29.29.29) 与阿里公共 DNS (223.5.5.5)。
  2. 安全 DOH Fallback 设置：境外则配置 Fallback 组使用安全加密的 DOH https://1.1.1.1/dns-query，绕过运营商污染。
  3. 开启 Sniffing (域名嗅探)：在 DNS 页面确保开启了 域名嗅探 开关。当客户端发起连接时，Stash 能够嗅探数据流中的 SNI 域名匹配正确的路由规则，杜绝了本地域名污染造成的解析错误。

六、高质量线路选择与常见断流排错

Stash 的流畅运行需要优质的出海物理线路作保障：

  • 针对日常追剧、超高吞吐 4K 播放场景，推荐选用全 1.0 倍率、原生支持 Vless 协议的低价高性价比提供商 快狸机场。
  • 若对晚高峰物理延迟与抗抖动有极高要求，可参考接入物理内网隔离专线的 光年梯 以及支持不限在线设备数、针对各类跨境 AI 服务进行出口优化住宅 IP 的 极连云 深度评测。

⚠️ Stash 连上后显示 Error 或无网自查：

若开启连接后显示异常，第一步请首先核对您的本地手机系统时间是否与标准北京时间一致。第二步，可以进入 Stash 底部的 连接 (Connections) 面板，实时监控每一个 TCP/UDP 请求的解析路径，准确定位排障。
