在苹果 iOS 生态下，Shadowrocket（因其黄色的图标，在科学上网界常被称为“小火箭”）绝对是无可争议的“国民级”代理客户端。虽然它是一款付费工具，但凭借低至 2.99 美元的良心定价、极简的交互界面、极低的运行耗电、以及对主流协议（Shadowsocks, Trojan, VMess, Vless, Hysteria 2, TUIC 等）的无缝全兼容，成为了每个苹果手机用户出海的首选伴侣。

然而，许多用户在使用小火箭时，经常陷入“误下山寨虚假软件”、“未在 iOS 系统层开启证书完全信任导致网页打不开”、“国内软件也被代理导致卡顿”等误区。本教程将由浅入深，从避坑安装、一键配置同步、模式智能选择，到高级的 HTTPS 解密与防劫持 DNS 优化，为您提供详尽指南。

一、防骗避坑：Shadowrocket 客户端的正确获取

由于苹果商店的监管政策，小火箭在中国大陆区的 App Store 是搜索不到的。在获取过程中，有以下两个核心痛点需要规避：

  1. 警惕山寨假冒应用：在大陆区 App Store 搜索 Shadowrocket，会跳出大量名字极度相似、甚至图标相似的虚假付费套壳软件（如各种“小火箭VPN”、“Shadowrocket Proxy”等）。这些山寨软件通常不仅无法导入您的订阅，还存在高额的订阅陷阱与账号安全泄露高危风险。
  2. 正确下载流程：
    • 准备一个非中国大陆地区的 Apple ID（推荐美区或港区，可在苹果官网自行注册）。
    • 打开 App Store，退出当前国区账号，登录您的海外 Apple ID。
    • 搜索唯一的官方应用 Shadowrocket（认准开发者为 Shadow Launch Technology Limited，图标为黄色小火箭）。
    • 小火箭售价为 2.99 美元。您可以购买对应地区的苹果 Gift Card（礼品卡）充值到余额中进行购买下载。

二、保姆级核心实操：机场节点导入

小火箭的节点导入非常人性化，支持二维码扫描、一键云链接同步以及手动订阅写入三种模式。我们以高性能中转专线机场为配合演示。

1. 自动一键导入（最推荐）

  1. 用 Safari 浏览器登录您的机场后台，例如以原生住宅 IP 和 Vless 协议著称的 快狸机场。
  2. 在首页的用户中心，找到“一键导入订阅”模块，点击“导入到 Shadowrocket / 小火箭”按钮。
  3. 浏览器会自动弹窗提示“是否在 Shadowrocket 中打开此链接？”，点击 打开。
  4. 客户端会自动拉起并完成节点数据的拉取，列表中会瞬间载入该机场的香港、日本、美国等核心加速节点。

2. 扫码或手动添加

如果您在电脑端登录机场后台，也可以直接使用小火箭扫码：

  1. 打开 Shadowrocket，点击主界面左上角的扫描二维码图标，对准网页上的小火箭订阅二维码进行扫描。
  2. 或者，点击右上角的 + (添加) 按钮，将类型（Type）切换为 Subscribe (订阅)。
  3. 在 URL 栏中粘贴从机场后台复制的“Shadowrocket/小火箭订阅链接”。在备注（Remarks）栏填写如 快狸机场。
  4. 点击右上角的 保存 (Save)。小火箭会自动同步节点。
  5. 开启启动更新：建议点击小火箭底部的 设置 (Settings) -> 订阅 (Subscribe)，开启 打开时更新 (Update on Launch)，确保您本地的节点状态永远与机场服务端保持同步。

三、三大代理路由模式详解

在小火箭主界面上方，有 全局路由 (Global Routing) 的选项，这是决定流量如何分流的中央处理器。点击可切换以下三种模式：

  • 配置 (Config - 强烈推荐)：智能分流模式。小火箭会依据本地挂载的 .conf 规则规则包，对每一个网络请求进行智能筛选。对于百度、微信、支付宝等国内应用直接走直连，不消耗机场流量且网速极快；对于 Google、Twitter、ChatGPT 则自动通过代理节点发送。如果您在使用 ChatGPT 时频繁遇到 IP 受限，可在配置模式下，利用规则集将 OpenAI 的访问强行绑定在纯净住宅 IP 上（具体的住宅 IP 解锁思路，也可参考支持多端大带宽的 极连云）。
  • 代理 (Proxy)：相当于其他客户端的“全局模式”。所有出站的 TCP/UDP 流量都会强行经由您选定的特定节点发送。适用于规则库中未包含的偏门境外服务。
  • 直连 (Direct)：关闭小火箭的所有代理链路，手机流量不经过任何加密通道，相当于直接访问。

四、极客优化：HTTPS 解密（MITM）与高级规则覆盖

为了实现精准的去网页内嵌广告、重写重定向以及脚本同步，小火箭也支持 MITM（中间人解密）。如果您开启了高级过滤去广告规则，必须配合进行如下 CA 证书配置：

  1. 生成并下载证书：在小火箭底部点击 配置 (Configuration) -> 选择当前处于激活状态的配置文件 -> 点击 编辑配置 (Edit Config) -> 进入 HTTPS 解密 (Mitm)。开启 Mitm 开关，并点击 生成新的 CA 证书 (Generate CA Certificate)。随后点击 安装证书 (Install Certificate)，下载描述文件。
  2. 安装描述文件：返回 iOS 手机系统的 设置 -> 已下载描述文件 -> 点击右上角安装并确认。
  3. 证书安全信任：依次进入手机系统 设置 -> 通用 -> 关于本机 -> 向下拉进入 证书信任设置。找到刚刚下载的 Shadowrocket CA 证书，打开其右侧的开关，使其处于绿色完全信任状态。
  4. 添加解密主机名：返回小火箭 HTTPS 解密页面，在主机名（Hostnames）列表中添加您需要解密的域名，点击保存即可。

五、网络质量优化：本地 DNS 劫持防范

iOS 系统在复杂的蜂窝网络和 WiFi 切换中，很容易发生本地域名劫持，导致网页加载“卡死”。

  • 添加 System DNS：在小火箭的 设置 -> DNS 面板中，国内首选添加阿里公共 DNS (223.5.5.5)，以实现国内常规寻址闪电返回。
  • 引入 DOH/DOT 安全解析：在 DNS 列表中添加 https://1.1.1.1/dns-query，当遇到海外网络请求时，小火箭会绕过运营商的劫持服务器，直接采用 HTTPS 加密向 Cloudflare 安全 DNS 查询目标 IP，从根本上解决运营商污染。

六、优秀机场搭配与常见问题自查

配置好小火箭后，一条高速稳定的线路至关重要：

  • 针对日常追剧、大文件大带宽传输需求，推荐搭配使用全 1.0 倍率、全线原生 Vless 协议的 快狸机场。
  • 若对晚高峰物理延迟与抗抖动有绝对要求，可参考物理内网专线的 光年梯 或针对 AI 住宅 IP 出口优化的 极连云 深度评测。

💬 常见故障自查 FAQ：

Q1: 为什么开启连接后，手机完全上不了网？
答：首次启动小火箭连接开关时，系统会弹出 VPN Configurations 写入弹窗。您必须点击 Allow（允许）并输入锁屏密码。如果误点了，请前往手机 设置 -> 通用 -> VPN 手动激活。

Q2: 为什么节点测速显示数值，但就是打不开 Google？
答：请在小火箭主页面长按该节点进行“连接测试”。请注意：点击节点测试出来的“Ping (毫秒)”仅代表物理网关的延迟，不代表代理节点已经连通。如果出现连通率低，请首先核对手机系统时间，偏差超过 60 秒将导致安全密钥验证失败直接断开连接。
