Quantumult X 配置教程

在苹果 iOS 生态的科学上网工具中，Quantumult X（俗称“圈X”） 始终被极客群体誉为性能最强悍、交互最优雅且流量可视化做得最极致的“第一神机”。不同于普通代理软件，圈X 凭借其独立自研的底层网络引擎，在处理数万条复杂路由分流规则时，依旧能够将设备的发热与电池损耗控制在极低的范围内。同时，它内置的脚本执行器、HTTPS 中间人解密（MITM）以及定时任务（Task/Cron）机制，使其不仅仅是一个网络分流工具，更成为了 iOS 平台上的“微型脚本服务器”。

然而，圈X 的配置门槛在业界也是出了名的高。许多新手在面对“资源解析器（Parser）配置”、“根证书安装却无法信任”、“本地 JS 脚本执行报错”等问题时，往往一头雾水。本教程将由浅入深，从应用安全获取、节点拉取、策略组手动映射，到核心的 MITM 根证书配置、Rewrite 插件以及 DNS 深度调优，为您提供详尽配置指南。

一、Quantumult X 的获取与注册准备

Quantumult X 是一款付费的闭源应用，为了保证您使用的安全性，请务必遵循正规渠道获取：

  1. 非中国大陆区 Apple ID：由于大陆区 App Store 的下架政策，您需要使用美区、港区、日区等非大陆的 Apple ID。
  2. 充值与购买：该软件在商店的正常售价为 7.99 美元。您可通过对应地区的苹果官方礼品卡进行礼品卡余额充值完成购买下载。
  3. 避免共用共享 ID：请尽量避免共用网络上的免费共享 Apple ID 下载，因为这不仅面临账号锁定或被锁机的高危风险，还会因为证书签名过期导致圈X 闪退、配置丢失。

二、基础实战：资源解析器配置与节点订阅拉取

圈X 原生仅支持其专属的 Quantumult X 节点描述格式，对于市面上绝大多数机场提供的 Clash 格式或通用 SS/Vmess 链接，直接复制导入通常会报错。这就需要引入圈X 的核心组件——资源解析器（Resource Parser）。

1. 开启并配置资源解析器

  1. 打开 Quantumult X，点击主界面右下角的大风车图标（配置主入口）。
  2. 向滑动，找到 配置文件 (Configuration) 模块下的 下载 (Download)，在输入栏中粘贴一份社区维护的解析器配置文件链接（例如：https://raw.githubusercontent.com/crossutility/Quantumult-X/master/parser.js）。
  3. 点击下载并确认覆盖本地。此时，解析器（Parser）将正式在本地网关层生效，它可以自动把任何 Clash、Shadowrocket、Loon 格式的订阅转换为圈X 原生节点。

2. 导入机场订阅链接

以我们常用的高性能 BGP 中转/IPLC 机场服务为例进行配置：

  1. 登录翻墙服务商后台。例如，使用住宅 IP 原生 Vless 节点的 快狸机场 或 极连云，在用户中心复制您的 Clash 订阅链接。
  2. 回到圈X，点击右下角大风车，在 节点 (Servers) 模块下选择 引用 (Resource)。
  3. 点击右上角 + 按钮新建订阅：
    • Tag (标签)：输入例如 快狸机场。
    • Resource Path (资源路径)：粘贴您复制的订阅链接。
    • 解析器 (Parser)：勾选启用。这一步极为核心，解析器会将订阅链接中的 Vless、Trojan 节点无缝转换为圈X 可识别的代理配置。
  4. 保存后向左滑动此订阅卡片，点击 更新 (Update)。圈X 即可成功将订阅节点全数拉取，并在首页的节点托盘中展示。

三、高级分流：规则集与策略组（Policy Groups）构建

圈X 的灵魂在于分流。在 分流 (Filter) 模块下，用户可以通过引用外部维护的规则集（如 Rule-Set）来实现国内直连、海外代理、广告拦截与特定服务定向路由。

  1. 新建策略组：点击大风车 -> 策略组 -> 添加。我们可以新建一个名为 🤖 OpenAI 的自定义分流组，类型选择为 static (手动选择)，然后将订阅中的优质美区、新加坡住宅节点（如 极连云 住宅节点）加入其中。
  2. 挂载分流规则集：在 分流 (Filter) 模块下点击 引用 (Resource)，添加远程规则链接。例如，导入针对 ChatGPT 域名的规则（如 host-suffix, openai.com, 🤖 OpenAI）。这确保每次向 ChatGPT 发起连接时，都会强行路由至已清洗过的干净 IP，彻底规避因 IP 封锁引起的 Access Denied 报错。
  3. 近距离与 Hysteria 2 协议支持：如果机场节点支持较新的 Hysteria 2 协议（多用于大吞吐量和低延迟传输，具体测评可以参考专线机场 光年梯），圈X 内置内核在搭配解析器后，也能实现极强的晚高峰抗拥堵物理支撑。

四、HTTPS 审计基石：MITM 解密与根证书深度信任

为了实现广告强力拦截、自动获取 Cookie 以及高级 JS 脚本重写，圈X 必须被授权能够对特定 HTTPS 流量进行解密。以下是根证书配置的保姆级三步走流程：

第一步：本地生成根证书

  1. 点击大风车，拉到最底部，找到 **工具 (Tools)** 模块下的 **生成证书 (Generate CA)**，点击进入。
  2. 开启 **Mitm 开关**。
  3. 点击 **生成 CA 证书 (Configure CA)**，圈X 将在本地运算并生成一套根证书。

第二步：下载与安装描述文件

  1. 证书生成后，点击 **安装证书 (Install Profile)**。
  2. 浏览器会自动唤醒 iOS 系统的描述文件下载模块，提示“此网站正在尝试下载配置描述文件”，点击 **允许**。
  3. 关闭弹窗，退出浏览器。

第三步：系统级完全信任根证书

  1. 打开 iOS 手机系统的 **设置 (Settings)**，点击最上方的 **已下载描述文件 (Profile Downloaded)** 进行安装并信任。
  2. 回到系统设置主页面，依次进入 通用 (General) -> 关于本机 (About)。
  3. 滑动到最底部，找到 **证书信任设置 (Certificate Trust Settings)**。
  4. 找到刚才安装的 Quantumult X 开头的证书，将其右侧的开关拨至绿色开启状态，并点击继续确认。

此时，Mitm 的解密权限已正式在系统层打通，您在访问被 Mitm 声明的主机域名（Hostnames）时，圈X 便能对网络封包进行本地加解密。

五、极客进阶：定时任务（Task/Cron JS 脚本）挂载

圈X 内部搭载了一个独立的 JavaScript 运行时引擎，允许极客在本地执行具有高频定时性质的 Cron 任务：

  • 脚本格式与挂载：在配置文件中，定时任务的配置语法为 0 8 * * * path/to/script.js, tag=每日签到。代表在每天早晨 8 点，自动调起 JS 引擎运行指定脚本。
  • 脚本数据持久化：JS 脚本可以通过圈X 原生提供的 $prefs.valueForKey() 等 API 来读写系统配置区，实现各种复杂的自动签到、积分同步与网络连接状态自查。

六、高级网络调优与落地机场推荐

调优本地 DNS 是杜绝 iOS 代理网络断流的终极手段：

  1. 打开大风车，进入 配置文件 (Configuration) -> 编辑 (Edit)，找到 [dns] 节点配置区。
  2. nameserver 配置：国内 DNS 解析首选阿里公共 DNS (223.5.5.5) 或腾讯 DNS (119.29.29.29)，防止国内解析出现死锁。
  3. fallback 配置：设置 fallback=https://1.1.1.1/dns-query，这样当遇到海外被劫持域名的解析请求时，圈X 会在本地直接调用 DOH（加密 DNS）向 Cloudflare 发起安全查询，杜绝本地污染。

配置完美的圈X，依旧需要底层配合一条足够纯净且晚高峰稳定的物理链路：

  • 针对日常追剧、大文件大带宽传输需求，推荐搭配使用全 1.0 倍率、原生 Vless 协议架构的 快狸机场。
  • 若对晚高峰物理延迟与抗抖动有绝对要求，可参考接入物理内网隔离专线的 光年梯 或支持不限在线设备数、针对各类跨境 AI 服务进行出口优化住宅 IP 的 极连云 深度评测。

⚠️ 圈X 节点超时（Timeout）与报错排障：

若出现全节点连接超时或报错，请第一步确认本地系统时间与标准北京时间偏差在 60 秒以内（偏差大会导致加密验证失败）；第二步请在主页面右上角开启 网络活动审计 (Activity Console)。在此面板可实时观测每一个 HTTP 请求究竟是在哪个规则下被拒绝（Reject）或是被代理（Proxy），这是极客排障的最强利器。
